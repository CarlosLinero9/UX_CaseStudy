## Practica 5: Exportación + Documentación - entregables 


- Exportación a HTML/React

Se ha realizado una primera versión funcional de **Punto Café** en **React + Vite**, usando como base las pantallas y componentes definidos en las prácticas anteriores.

**Evidencia:** [Exportación React](./1-ExportacionReact/PuntoCafeReact/)

Para ejecutarlo:

```bash
cd P5/1-ExportacionReact/PuntoCafeReact
npm install
npm run dev
```

- Documentación con Storybook

No se ha montado Storybook, pero se ha preparado una documentación breve de los componentes UI principales de la versión React, indicando su función dentro de la interfaz.

**Evidencia:** [Documentación de componentes](./2-Documentacion/Componentes_UI.md)

- Autoevaluacion del diseño 
Puntos fuertes y de mejora relativos a los criterios de accesibilidad de tu diseño

**Puntos fuertes:**

- Interfaz clara y coherente.
- Diseño orientado a móvil.
- Botones y tarjetas fáciles de identificar.
- Navegación sencilla entre secciones.

**Puntos de mejora:**

- Revisar contrastes y accesibilidad.
- Añadir validación en formularios.
- Completar funcionalidades reales como carrito persistente y filtros activos.
- Probar con más usuarios reales.


- Conclusiones

La exportación a React ha permitido comprobar que el diseño de **Punto Café** puede trasladarse a una aplicación funcional basada en componentes. Aunque no es una versión final, sirve como base para seguir mejorando la interfaz, la accesibilidad y la funcionalidad del proyecto.
